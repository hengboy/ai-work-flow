# Project Context Contract

`MEMORY.md` 保留并至多各有一个“领域术语、仓库约束、职责、模块边界”章节。已有同义章节合并，不复制。用户内容不放入 managed marker，也不被生成逻辑覆盖。

`.ai-work-flow/index/feature-navigation.md` 使用简短表格记录业务关键词、入口相对路径和模块边界。前端/后端索引只在对应层真实存在时创建。移动、删除、拆分、合并或主职责变化时，同轮更新索引；职责边界变化同步更新 MEMORY。

项目指令只补一条稳定维护规则：修改入口或职责时同步维护 MEMORY 和索引；评审以 committed MEMORY 为 standards source。不得复制整份工作流协议。
