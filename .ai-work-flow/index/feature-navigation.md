| 功能/关键词 | 入口路径 | 模块边界 |
| --- | --- | --- |
| CLI 安装、初始化、验证、生成 | `agent-build/install.mjs` -> `agent-build/runtime/workflow.mjs` | CLI 转交 `runCli`；安装时只补齐完全缺失的 Planning 或 Task Planner 配置，并将迁移、核心 runtime/资产与平台代理生成放入同一事务；残缺配置失败，`validate` 和 `--dry-run` 不写。 |
| 工作流命令、环境管理 | `agent-build/runtime/workflow.mjs` | 依赖 `agent-build/runtime/config.mjs`、`agent-build/runtime/transaction.mjs`、`agent-build/runtime/asset-catalog.mjs`、`agent-build/runtime/paths.mjs`、`agent-build/runtime/platform-adapter.mjs`；托管 Skill 目录通过目录事务与配置、资产和 Agent 共同提交。 |
| Agent 角色、Policy、路由资产 | `agent-build/config/roles.json`、`agent-build/config/policies.json`、`agent-build/config/routing.md`、`agent-build/templates/*.md` | 12 个受管理角色包含 Planning、Task Planner、Researcher、Coding、Git Committer 和 Code Reviewer；Researcher 只研究外部官方资料，并将 Markdown 报告写入 `.ai-work-flow/research/`；Asset catalog 允许多个 primary、校验唯一 `default_primary`；routing 按 browser、handoff、retry、implementation、review 关注点组合共享治理，角色正文保留本地职责。 |
| 平台 Agent 生成 | `agent-build/runtime/platform-adapter.mjs` | 生成各平台 Agent 配置与托管内容；Planning 为无直接文件访问的协调角色，仅保留委派能力；OpenCode 将 Researcher 写入限制为 `.ai-work-flow/research/*.md`。 |
| 项目代码导航规则 | `skills/project-code-navigation/SKILL.md` | 维护 `.ai-work-flow/index/` 下的功能导航。 |
| 目录式计划与任务 | `agent-build/templates/planning.md`、`agent-build/templates/task-planner.md`、`agent-build/templates/planning-writer.md` | Planning 先展示完整 `.ai-work-flow/plans/<plan-id>/plan.md`；拆分时 Task Planner 先返回不落盘的完整草案，用户确认颗粒度后才写入 `tasks/NN-short-name.md`，再确认 planning commit；无 `tasks/` 为单任务，空或无效目录阻塞。 |
| 计划实施路径 | `agent-build/templates/coding.md`、`agent-build/templates/git-committer.md`、`agent-build/templates/code-reviewer.md` | 单任务只委派一个 Full Stack Coder；拆分按依赖前沿并发，每个 task 的实现与 checkbox 进入 task review commit，逐 task 双轴评审后按编号汇入，最终聚合双轴评审并 `--ff-only` 整合。 |
| Spec、Ticket 执行 | `execution-runtime/execution-cli.mjs`、`skills/run-matt-spec-to-completion/lib/execution-coding.mjs` | CLI 是 prepare/claim/record/sync/review/fix/integrate/cleanup/status 的唯一状态入口；同步冻结 `main_commit`，冲突由实施角色解决。 |
| Ticket Handoff、Git 路径与审查清单 | `skills/run-matt-spec-to-completion/lib/{paths,git,review-manifest}.mjs` | `paths` 定义并比较 PathChange，`git` 唯一解析 porcelain v2 `-z`，`review-manifest` 冻结 digest、双轴分片和 coverage。 |
| 执行计划、Checkpoint | `execution-runtime/state-store.mjs`、`skills/run-matt-spec-to-completion/lib/checkpoint.mjs`、`skills/run-matt-spec-to-completion/lib/checkpoint-integrity.mjs`、`skills/run-matt-spec-to-completion/lib/ticket-frontier.mjs` | state store 是唯一 writer；Checkpoint 保存同步状态、结构化双轴 Review Result、评审尝试和整合门禁，完整性校验 Git 身份、review range 和 fast-forward 条件。 |
| 测试 | `test/agent-workflow.test.mjs`、`package.json` | `package.json` 的 `test` 脚本使用 Node 测试运行器。 |
